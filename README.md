# dotfiles (DEPRECATED)

This repository has been deprecated in favor of [workstation](https://github.com/johnnymo87/workstation), which manages all machine configuration via NixOS, nix-darwin, and home-manager.

All shell aliases, git config, tmux config, neovim config, GPG setup, and tool installations that were previously managed here are now declared in the workstation flake.

This repo is kept around only as a reference for the migration history.
